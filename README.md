# Agent Trajectory Marketplace

Collect credential-redacted coding-agent trajectories and publish reviewed
candidate bundles to the official ATM gateway.

## Install

```bash
curl -fsSL https://github.com/effortprogrammer/agent-trajectory-marketplace/releases/latest/download/install-agent.sh | bash -s -- --dir atm
```

Requires Git and Bun 1.3 or newer.
